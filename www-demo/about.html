About webserv

webserv is a project from the 42 School cursus. The goal is to build an HTTP/1.1 server in C++98, with no high-level networking libraries, and to learn how production web servers really work under the hood.

🎯 Goal

Implement a configuration-driven HTTP server inspired by NGINX, using only the C++98 standard and POSIX sockets.

📚 What we learned

HTTP message parsing, non-blocking I/O with poll(), CGI execution, multipart bodies and edge cases in real-world clients.

🧱 Architecture

A single-threaded event loop. Every socket — listeners, clients and CGI pipes — goes through the same poll() array.

⚙ Configuration

A custom config format describing servers, listen ports, server names, routes, methods, redirects, CGI and error pages.

🧪 Compliance

Tested against real browsers and against curl / siege for robustness, partial reads, chunked bodies and slow clients.

🏫 Context

This site is the demo we use during peer evaluation. It exercises each required feature with a dedicated page.
