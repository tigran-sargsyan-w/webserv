// autoindex

Autoindex / directory listing

When a directory has no index file and autoindex on; is set, the server should generate an HTML listing of its contents.

📁 Browse /files/

Configured demo directory. Should show a generated listing if no index file is present.

📁 Browse /public/

Alternate directory you can wire up in your config to test autoindex on a second route.

ℹ How to enable

In your config, on the matching location block:

location /files/ {
    root        ./www;
    autoindex   on;
}
