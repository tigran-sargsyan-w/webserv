Features

Everything below is implemented in our C++98 server and exercised by the demo pages in this site.

GET Static files

Retrieves files under a configured root, with MIME type detection and proper status codes.

POST Submit data

Accepts request bodies for CGI scripts and upload routes.

DELETE Remove resources

Removes a resource on disk when the route allows it.

📤 File upload

Stores request bodies to the configured upload directory.

🐍 CGI

Executes Python and shell CGI scripts and pipes their output back to the client.

📂 Autoindex

Generates a directory listing page when autoindex on; is set and no index file exists.

🚧 Custom error pages

Serves project-styled 4xx/5xx pages per the error_page directive.

🔀 Redirection

Returns 301/302 responses configured per route.

🍪 Sessions

Bonus demo with Set-Cookie, server-side session state, counter and logout.

🧱 Multiple servers

Bind several listen directives with independent server_name and roots.

HTTP methods

  • GET   safe, idempotent; serves a resource or runs CGI
  • POST   accepts forms, CGI input and uploads
  • DELETE   removes a resource if the route allows it
