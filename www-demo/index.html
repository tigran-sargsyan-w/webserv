webserv — A C++98 HTTP Server

A small, non-blocking HTTP/1.1 server written from scratch in C++98. Inspired by NGINX, built to learn sockets, parsing, CGI and configuration-driven routing.

▶ Try the demo View features About the project

What it does

Configuration-driven HTTP server with support for the methods and behaviors required by the 42 webserv subject.

  • GET Serve static files from configured roots.
  • POST Accept form submissions and uploads.
  • DELETE Remove resources on disk.
  • CGI Execute Python / PHP scripts and pipe their output.
  • AUTO Generate directory listings when index files are missing.

Core features

Each card maps to a real requirement from the webserv subject.

⚡ Non-blocking I/O

A single poll() loop multiplexes every client, accept and CGI pipe — no thread per connection.

📄 Static serving

Serve HTML, CSS, JS and assets from any configured root with proper MIME types.

🔁 GET / POST / DELETE

The three methods required by the subject are fully parsed and routed.

📤 File uploads

Parse multipart/form-data and store uploads in a configured directory.

🐍 CGI support

Execute Python or PHP scripts and stream their stdout back to the client.

🚧 Custom error pages

Per-server error_page directives, with consistent styling.

📂 Autoindex

Auto-generated directory listings when no index file is present.

🔌 Multiple ports

Bind several listen blocks with different configurations on the same binary.
