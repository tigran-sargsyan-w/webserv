How webserv chooses a route

A short public note about route resolution in this demo server.

Route matching

The server receives an HTTP request, extracts the clean path, and maps it to the best configured location. In this demo, pages are served from the root location, uploads from /uploads, CGI scripts from /cgi-bin, and public notes from /public.

Static files

Regular files are returned with a MIME type and a normal 200 OK response.

Directories

If no index file exists and autoindex is enabled, webserv generates a directory listing.

Errors

Unknown paths are mapped to styled custom error pages instead of raw debug output.
