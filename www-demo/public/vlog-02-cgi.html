CGI as a dynamic endpoint

This note explains what the CGI demo is meant to prove during evaluation.

What CGI receives

A CGI script receives request metadata through environment variables and request body data through stdin. The demo includes GET, query string handling, POST body handling, a custom Status header, and a timeout scenario.

Python

.py scripts are executed with /usr/bin/python3.

Shell

.sh scripts are executed with /bin/sh, demonstrating multiple CGI types.

Timeout

The slow CGI script should be interrupted and returned as 504 Gateway Timeout.
