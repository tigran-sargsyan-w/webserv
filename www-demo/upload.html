File upload

Choose a file and send a regular browser multipart upload to a route with upload_enable on;.

ℹ Notes for evaluators

Submitting this form sends a real multipart/form-data request to /uploads. The server extracts the uploaded file name from the multipart headers and stores only the file content in the configured upload directory. After upload, open /uploads/ to see the saved file through autoindex.
