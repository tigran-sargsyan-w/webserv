// about the project

A C++98 HTTP server

WebServ is a 42 School project focused on sockets, non-blocking I/O, HTTP parsing, routing, CGI and configuration.

View features Back home

Non-blocking I/O

A poll-based event loop handles listeners, clients and CGI pipes.

Configured routing

Server and location blocks control roots, methods, redirects, uploads and CGI.

HTTP methods

GET, POST and DELETE requests are parsed and dispatched to dedicated handlers.

Browser demo

These pages provide simple manual checks for the main server features.
