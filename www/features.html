WebServ features

A compact overview of the HTTP features implemented by the project.

Static GET

Serve HTML, CSS, JavaScript and other files.

POST uploads

Accept request bodies and multipart file uploads.

DELETE

Remove resources from configured upload directories.

CGI

Execute configured Python, shell or PHP scripts.

Autoindex

Generate directory listings when enabled.

Sessions

Cookie-backed server-side session demo.

Redirects

Return configured 301 responses.

Error pages

Serve custom pages for common HTTP errors.
