What this proves

The cookie contains only the session id. The real session state lives on the server.

✅ Cookie parsing

The server reads the incoming Cookie header and extracts sid.

✅ Session restore

The same sid restores the same server-side session data.

✅ Session state

The visit counter changes on the server without being stored in the cookie.

✅ Logout

The logout endpoint destroys the session and expires the cookie with Max-Age=0.
